# 示例：中国大模型混战史（46.9s）

用 FactReel 流程完整走通的一条片子，作为格式与纪律的参照样例。

## 走法回顾
1. **查证**：8 个时间节点（2023-03 首发 → 百模大战 → 长上下文出圈 → 价格战 → 开源模型震动海外市场 → 开源周 → 2026 智能体竞争）逐个联网核对日期与关键数字后才进入事实表。
2. **写稿**：10 句旁白，Beat 0 钩子「三年混战四十秒讲完」，末句以站队问题收尾引评论。
3. **配音计时**：逐句生成配音并用 ffprobe 实测（单句约 3.1–5.1s，总 41.6s 旁白），分镜时长全部由实测驱动；成片 46.9s（含片头片尾留白）。
4. **字幕**：句级时间为实测；句内逐字高亮按字数比例估算 — 在交付说明中明示为估算（本 skill 的诚实分级示例）。
5. **校验**：成片 1080×1920 / 30fps / h264 + aac，关键静帧抽查字幕不遮信息。

## 旁白稿（结构示意）
| Beat | 内容指向 |
|---|---|
| 0 | 钩子：三年混战，一次讲完 |
| 1–2 | 起点与百模大战 |
| 3–4 | 长上下文出圈、价格战 |
| 5–7 | 开源模型发布、海外市场反应、开源周 |
| 8 | 战场转向智能体 |
| 9 | 收束 + 站队问题 |

> 具体数字以事实表与片尾来源卡为准；本示例只展示流程与结构，不替代查证。
