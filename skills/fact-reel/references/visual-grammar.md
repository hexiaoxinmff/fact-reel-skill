# 视觉语法（v0.1：时间线卡片模板）

## 画布
- 1080×1920，30fps。安全区：顶部 120px、底部 260px（字幕带与平台 UI 遮挡区）不放关键信息。

## 版式
- 一 Beat 一卡：顶部章节/时间标签，中部主信息（大数字优先），底部字幕带。
- 主数字字号 ≥ 120px；每卡文字 ≤ 3 个信息块。
- 时间线类题材：底部或侧边放进度节点，当前节点高亮，已过节点变暗。

## 动效原则
- 动效只服务信息：数字增长、节点点亮、对比条伸长。无目的的漂移/旋转不要。
- 转场 ≤ 8 帧；信息先于装饰出现。

## 标注位
- 估算/插值脚注：卡片右下小字，与主信息同屏，不藏片尾。
- 示意复刻：涉及重演对白/文书时，画面固定角标「示意复刻」。
- 来源：片尾来源卡统一呈现（机构 + 日期），正文卡片不堆链接。

## 静帧评审（门 2）
至少渲 3 帧：钩子帧、中段最密信息帧、结尾帧。检查：字幕带不遮信息、大数字不溢出、脚注可读。
