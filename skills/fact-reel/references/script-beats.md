# 写稿规范（Beat 脚本）

## 结构
- **Beat 0 钩子（0–3s）**：一句话给出全片最反常识/最有 stakes 的点，不铺垫背景。
- **中段 Beats**：一个 Beat = 一句旁白 = 一个信息点。按时间线或因果链排序，不跳跃。
- **末 Beat**：收束结论 + 一个观众能站队/能回答的问题（为评论而设计，不是口号）。

## 时长预算
- 目标总时长 30–45 秒；每句实测约 3.5–5 秒。
- 40 秒 ≈ 9–11 句。写稿时按句数控时长，渲染后以实测为准。

## 句子纪律
- 每句只装一个事实动作；两个数字挤一句 = 拆两句。
- 数字念稿化：年份逐位读（「二零二五」），金额带单位与币种，百分比说清基数（若事实表有）。
- 不用无出处的程度词：「震惊」「碾压」「彻底」必须有事实表支撑，否则删。
- 专名第一次出现给全称，之后可用简称。

## 反例
- ✗ 「据说某模型用户已经好几亿了」— 无来源、无口径
- ✓ 「二零二六年六月，某助手月活三点八二亿（来源：XX 报告）」— 有数、有口径、有出处（片尾来源卡呈现）
